Fairness and Stability in Stateless Replica Placement: Lower Bounds and Calibrated Order Sampling

Manuscript author: Huynh Anh Khiem, Faculty of Information Technology, Ton Duc Thang University, Vietnam.

This repository currently contains an exact rational verification script for the four-corner k=2 certificate, and its recorded result. The complete experimental archive (ESM_2.zip), including Ceph fixtures, third-party licenses, experiments, reproduction instructions and recorded outputs, is supplied as supplementary material with the manuscript. The complete archive has not yet been uploaded to this repository.

Run the certificate from the repository root with:
  python3 src/exp/certificate_rectangle.py

The script uses Python's standard library only. It verifies the eight-atom coupling witness, not the entire universal lower-bound proof. See LICENSE.txt for the original software copyright notice. Third-party files in the complete supplementary archive retain their own licenses.
